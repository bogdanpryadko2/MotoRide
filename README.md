# MotoRide

## Лабораторная работа №1

по дисциплине **«Технологии Web-программирования»**

---

### Тема проекта

Шаблон веб-приложения на тему **«Спортивные мотоциклы для настоящих мужиков»**.

---

### Состав работы

Проект представляет собой одностраничное веб-приложение с переключением между четырьмя разделами через навигационное меню.

| Страница | Описание |
|----------|----------|
| **Главная** | Приветственный блок с тегом и карточки четырёх культовых супербайков: YZF-R1, Panigale V4, Fireblade SP, Ninja H2. Для каждого указаны объём двигателя, мощность, краткое описание и тег. |
| **О мотоциклах** | Информационная страница с текстом о спортивных мотоциклах, инженерии и технологиях. Боковая панель содержит список лучших моделей и ключевых технологий. |
| **Вход** | Форма авторизации с полями Email и Пароль. Присутствуют ссылки на восстановление пароля и переход к регистрации. |
| **Регистрация** | Форма создания аккаунта с полями: имя, email, пароль и подтверждение пароля. Имеется ссылка на страницу входа. |
